# 🌌 Better Space – Terraria Mod

## 📖 Description

**Better Space** is a simple Terraria mod created to experiment with the tModLoader modding environment.

The goal of this project is to modify the appearance of the sky when the player reaches high altitude. Instead of the default Terraria space background, the mod displays a custom orbital-style sky.

This project was created as a learning exercise to understand how Terraria's sky rendering system works and how to implement custom visuals using tModLoader.

## 🛠️ Technologies Used

* **C#**
* **tModLoader**
* **Terraria Modding API**
* Custom textures and assets

## ⚙️ Features

The mod introduces the following functionality:

* Replaces the **default space background** with a custom orbital sky
* Activates the custom sky when the player reaches **high altitude**
* Uses Terraria’s **CustomSky system** to render the background
* Supports smooth activation and deactivation depending on player position
